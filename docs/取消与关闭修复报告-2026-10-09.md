## 1. 当前行为

取消事件贯穿 Web 任务规划、Agent 工具、Qwen HTTP、ReAct 工具选择、最终问答和恢复执行。取消后不再进入 JSON 修复、视觉 fallback 或拆批重试。运行任务和请求记录保存为 `cancelled`；取消前已提交的回答保留原终态与重放结果。

HTTP 使用可终止的客户端进程承载阻塞网络操作，支持等待响应头、读取响应体和逐行流式输出。进程运行当前 Python 的标准库脚本，请求及认证头经 stdin 传入，不进入 argv 或临时文件。取消或超时会终止客户端、关闭连接并回收监控线程。没有取消作用域的既有调用继续使用原 urllib 路径。

`WebService.close()` 先拒绝新任务和聊天，设置取消事件，同步排队任务终态；随后等待执行线程与活跃同步操作退出，再关闭数据库。重复及并发 close 有回归覆盖。Unix `SIGTERM` 和 Ctrl+C 进入这条清理路径，关闭期间重复信号不会打断排空；即使服务清理报错，监听 socket 仍会关闭，并恢复原信号处理器。

| P2 | Job 发布与 Future/Event 登记分离，submit 与 cancel/close 并发可产生 KeyError 或调度失败，留下非终态记录。 | 在同一生命周期锁内登记；执行器拒绝调度时记录失败终态。首批 6 项关闭/竞争回归修前全部失败。 |
